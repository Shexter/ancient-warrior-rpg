# Terminal engine (`src/engine/`, `src/platform/terminal_*.cpp`)

- **Framebuffer:** a grid of `Cell{glyph, fg, bg}`. Drawing calls clip silently; `at()` requires in-bounds coordinates. `text()` is ASCII only (other bytes show as `?`).
- **Renderer:** `present(frame, out)` appends escape bytes for only the cells that changed since the last frame, wrapped in synchronized-update markers (`ESC[?2026h`/`l`). A first frame, a size change or `invalidate()` clears the screen and redraws everything. An identical frame appends nothing. Colors are truecolor, or the 256-color cube in `Ansi256` mode. Colors and cursor position are re-learned on every present, and the cursor is treated as unknown after the last column.
- **Color mode:** `platform::detectColorMode()` is truecolor if `COLORTERM` is `truecolor`/`24bit` or `WT_SESSION` is set, otherwise 256-color.
- **Input:** `InputDecoder` turns raw POSIX bytes into keys: arrows (`ESC [ A-D` and `ESC O A-D`), Enter (`\r`, `\n`), Backspace (127, 8), Tab, printable characters, and a lone ESC. Other escape sequences and control bytes are dropped. Each `feed()` is parsed on its own, so a sequence split across two reads is not reassembled. Windows reads key-down events natively.
- **Loop:** fixed 1/60 s steps with at most 5 steps per frame (extra time is dropped). Keys go to the first step after they arrive, once, and wait if a frame runs no step. The terminal size is checked every frame: below 80x24 only the centered resize prompt is drawn, `update` is skipped and keys typed meanwhile are dropped. In a larger terminal the 80x24 canvas is centered and the margin is filled with the loop's background color.
- **Terminal (POSIX):** raw mode with `ISIG` kept, alternate screen, hidden cursor. It restores on normal exit, on `SIGINT`/`SIGTERM`/`SIGHUP`/`SIGABRT` (then re-raises the signal; `SIGABRT` covers failed asserts) and via `atexit`. Restoring is idempotent and signal-safe. Not handled: `SIGTSTP` (Ctrl+Z) leaves the terminal raw while suspended. The constructor throws if stdin or stdout is not a terminal.
- **Terminal (Windows):** same contract using console modes, UTF-8 output code page and a console control handler. Written and compile-checked, but not yet run on Windows.
